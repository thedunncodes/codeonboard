## How to Add the MCP Server to Bob IDE

Bob IDE requires you to **manually configure** the MCP server in the settings. Here's the step-by-step process:

### Step 1: Open MCP Settings
1. In Bob IDE, go to **Settings** (gear icon or File → Preferences → Settings)
2. Look for **"MCP Servers"** or **"Model Context Protocol"** section
3. You should see options to view/edit global or project-level MCPs

### Step 2: Add New MCP Server Manually
Click **"Add Server"** or **"New MCP Server"** and enter these details:

**Server Name:**
```
codeonboard
```

**Command:**
```
python
```

**Arguments:** (as a JSON array or separate fields)
```json
["-m", "src.codeonboard.server"]
```

**Working Directory:**
```
//wsl.localhost/Ubuntu/home/heiwa/hackathon/codeonboard
```

**Environment Variables:** (add each one separately)
- `GITHUB_TOKEN` = `${env:GITHUB_TOKEN}` (or your actual token)
- `WATSONX_API_KEY` = `${env:WATSONX_API_KEY}` (or your actual key)
- `WATSONX_PROJECT_ID` = `${env:WATSONX_PROJECT_ID}` (or your actual ID)
- `WATSONX_URL` = `${env:WATSONX_URL}` (or your actual URL)

### Step 3: Choose Project-Level Configuration
- Select **"Project Level"** if you want this MCP server only for this project
- Select **"Global Level"** if you want it available in all Bob IDE projects

### Step 4: Save and Restart
1. Click **"Save"** or **"Apply"**
2. Restart Bob IDE or reload the MCP servers
3. The three tools should now appear in your Tools panel
