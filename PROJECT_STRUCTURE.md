## 🔧 MCP Tools Interface

### Tool 1: `fetch_repository`
Fetches a GitHub repository and caches its structure and metadata.

**Parameters:**
- `repo_url` (string, required): GitHub repository URL
- `include_content` (boolean, optional): Whether to fetch file contents
- `max_depth` (integer, optional): Maximum directory depth to analyze

**Returns:**
- Repository metadata (name, description, stars, language)
- File structure tree
- Key files identified (README, config files, entry points)

### Tool 2: `generate_onboarding_guide`
Generates a comprehensive onboarding guide using watsonx AI.

**Parameters:**
- `repo_url` (string, required): GitHub repository URL
- `include_diagrams` (boolean, optional): Generate Mermaid diagrams
- `detail_level` (string, optional): basic/detailed/comprehensive

**Returns:**
- Markdown-formatted onboarding guide with:
  - Project overview and purpose
  - Tech stack and dependencies
  - Architecture overview with diagrams
  - Setup instructions
  - Key files and their purposes
  - Development workflow

### Tool 3: `ask_codebase`
AI-powered Q&A about the repository using watsonx.

**Parameters:**
- `repo_url` (string, required): GitHub repository URL
- `question` (string, required): Question about the codebase
- `context_files` (array, optional): Specific files to focus on

**Returns:**
- AI-generated answer based on repository context
- Relevant code snippets
- File references
